# More World Presets

A Minecraft mod for **Fabric 1.20.1/1.21.1/26.1** that adds various world presets and enhances the world creation screen.

## Overview

**More World Presets** expands the default Minecraft world generation options by adding unique presets such as:
- **Skyblock**: Start on a small island in the void.
- **Skygrid**: A grid of random blocks in the void.
- **Oneblock**: Survive on a single block that regenerates when broken.
- **Winter**: A frozen wasteland preset.
- **Challenge Worlds**: Specialized worlds with unique constraints.

The mod also updates the World Creation screen to provide a better user interface for selecting these presets.
